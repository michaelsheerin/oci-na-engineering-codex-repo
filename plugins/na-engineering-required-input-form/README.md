# NA Engineering Required Input Form

Install this Codex plugin once to let NA Engineering skills collect non-sensitive Required Inputs in a Codex form.

## One-time setup

1. Open a terminal and run:

   ```powershell
   codex plugin marketplace add https://github.com/michaelsheerin/oci-na-engineering-codex-repo.git --sparse .agents/plugins --sparse plugins/na-engineering-required-input-form
   ```

2. Open Plugins, choose the new NA Engineering marketplace, then install **NA Engineering Required Input Form**.

The form service sends no requests to Oracle systems and stores no submitted values. Do not enter passwords, API keys, access tokens, payment data, or other secrets into a form.
