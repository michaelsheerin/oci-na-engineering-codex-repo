# Browse the Prompt and Skill Library

Open the live [Browse workflows page](https://michaelsheerin.github.io/oci-na-engineering-codex-repo/) for full-text search, category and creator filters, sorting, prompt copying, and `SKILL.md` downloads.

Each published workflow has two outputs: a reader-friendly Markdown record under [`prompts/`](../prompts) and a paired Codex skill under [`skills/`](../skills). Copy prompt text for one task. Download `SKILL.md` when you want the workflow available in future Codex tasks.

Use [Submit a workflow](https://oci-na-engineering-prompt-library.msheerin01.workers.dev/?view=submit) to publish both files together.
